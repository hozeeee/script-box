如何使用？

三步即可在 Script Box 或任意终端中运行。

  1. 下载脚本

    选择需要的工具，点击下载，保存一个独立的 .js 文件。无需下载整个项目。

  2. 选择运行方式

    导入 Script Box 的普通运行空间，选择 Node.js 22+。也可以在已安装 Node.js 22+ 的终端中运行。

  3. 设置参数并运行

    展开脚本的使用示例。在 Script Box 的运行配置中只填写参数，不需要添加 node 或脚本文件名。

  • 这些是 Node.js 脚本，网页只提供下载，不会在浏览器中运行。相对文件路径以运行时工作目录为准，建议使用绝对路径；路径中包含空格时请加双引号。以连字符开头的文件名可放在 -- 后。
  • 产物使用 CommonJS。在声明了 "type": "module" 的工程中使用时，请将下载文件后缀改为 .cjs。SHA-256 校验值可用于检查下载是否完整。
